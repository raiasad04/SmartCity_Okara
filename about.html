Research Workflow

Project Timeline

The four-phase pipeline from raw OSM data to a live published Smart City dashboard.

Phase 01
Data Acquisition & Pre-processing
OpenStreetMap data for Okara City downloaded using Python OSMnx — road networks, building footprints, amenities (schools, hospitals, fuel, markets, bus stops), and land-use polygons. All datasets reprojected to EPSG:32642 (UTM Zone 42N) for accurate metre-based distance calculations.
Python OSMnx GeoPandas EPSG:32642 GeoPackage
Phase 02
Conflict Detection via Buffer Analysis
500-metre safety buffers generated around all 31 sensitive locations (schools, hospitals, clinics, colleges). Spatial intersection used to identify facilities — fuel stations, marketplaces, and bus terminals — falling inside any buffer. Five conflict zones confirmed with reasons and relocation solutions assigned.
Buffer Analysis Spatial SQL ST_DWithin GeoPandas GeoJSON export
Phase 03
AHP-MCDA Suitability Scoring
Analytic Hierarchy Process applied to score every candidate residential zone 0–100 across multiple weighted criteria. EV stations weighted by road proximity (50%), city centre access (30%), and safety (20%). Waste hubs by residential proximity (60%) and road access (40%). Green corridors by peripheral location (60%) and open land (40%). Top 5 sites identified per category.
AHP MCDA NumPy Pandas CR < 0.10
Phase 04
Cartographic Maps & Web Dashboard
All GeoJSON outputs converted to EPSG:4326 for web rendering and loaded into QGIS for four high-resolution cartographic PDF maps. This interactive web dashboard built with Leaflet.js, featuring Before/After swipe comparison, layer toggles, satellite view, and popup detail panels. Deployed on GitHub Pages.

About This Project

Transforming Okara into a Smart City

This final-year GIS project performs a comprehensive Spatial Suitability Analysis for Okara City, Punjab, Pakistan. Using OpenStreetMap data, Python GeoPandas, and the Analytic Hierarchy Process (AHP), the study identifies badly-placed urban infrastructure and proposes scientifically-optimal locations for modern smart city facilities.

The research is built on two core pillars — Urban Conflict Resolution and Smart Infrastructure Site Selection — validated by mathematical MCDA weighting with AHP Consistency Ratios below 0.10.

🔴
Urban Conflict Resolution
Identifying fuel stations, bus stands and markets that violate 500m safety buffers around schools and hospitals — with relocation solutions.
✦
Smart Infrastructure Siting
AHP-MCDA multi-criteria scoring to find the top 5 locations each for EV charging stations, IoT waste hubs, and green corridor development.

Technical Methodology

How the Analysis Works

A four-phase pipeline from raw OSM data to an interactive Smart City dashboard.

Phase 01
📡
Data Acquisition
OSMnx · GeoPandas · EPSG:32642
Downloading building footprints, road networks, amenities, and land-use polygons for Okara City using Python and OpenStreetMap APIs.
Phase 02
🔍
Conflict Detection
Buffer Analysis · Spatial SQL · PostGIS
Creating 500m safety buffers around schools and hospitals, then using spatial intersection to flag any fuel stations, markets, or bus stands within those zones.
Phase 03
📊
AHP-MCDA Scoring
Analytic Hierarchy Process · NumPy · Pandas
Assigning mathematical weights to decision criteria — road proximity, residential density, safety distance — to score every candidate zone 0–100.
Phase 04
🌐
Web Dashboard
Leaflet.js · GeoJSON · GitHub Pages
Exporting all analysis outputs as GeoJSON and building this interactive Before/After web dashboard with layer controls and popup detail panels.
